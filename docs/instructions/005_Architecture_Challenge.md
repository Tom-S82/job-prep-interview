# Build Step 004: Architecture Challenge Mode

## Scope
Interactive scenario where user is presented with:
- A thinkmoney business problem (e.g., "We need to add real-time fraud detection to our platform. How?")
- Current platform constraints (SQL Server + SSIS, medallion partially broken)
- User designs/sketches solution

## Features
- Scenario picker (5–10 thinkmoney scenarios)
- Markdown editor or diagram canvas (optional draw)
- "Show expert answer" button (what would you, the Lead, actually do?)
- Feedback on their approach (what you got right, gaps, tradeoffs to consider)

## Examples
1. "Real-time fraud detection on transaction streams"
2. "Self-serve data access for Business Analysts (build the MCP semantic layer)"
3. "Migrate 50k legacy SSIS jobs to cloud—what stays, what goes?"
4. "A new Data Scientist needs cleaned data in 24h. Current platform is slow. Fix it."
